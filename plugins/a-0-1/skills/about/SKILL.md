# About A-0-1

A-0-1 is a system for running AI agents like a team: agents with defined roles, shared conventions, and a ticket-driven way of working.

This is the early release. It installs the system plugin only. The skills and agents are being added as they are reviewed for public release.

Read more at https://agents.assoc.one. Licence: CC BY-NC-SA 4.0.
